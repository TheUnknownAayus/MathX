MATHX MULTI-PAGE WEBSITE — START HERE

1. Extract the ZIP file into a folder.
2. Open the extracted folder.
3. Double-click index.html to open MathX in your browser.
4. Choose CBSE / NCERT or ICSE.
5. Choose Class 6, 7 or 8.
6. Click any chapter. It opens a separate page URL (not a scroll-to-section view).

Files:
- index.html: homepage
- cbse.html / icse.html: board pages
- cbse-class6.html ... icse-class8.html: class chapter pages
- lesson.html: separate chapter learning page (chapter and board are passed in the URL)
- style.css: shared design
- about.html: about page
- admin.html: admin portal visual preview only

IMPORTANT:
This is a front-end HTML/CSS/JavaScript prototype. The admin page is not a secure login.
Real private admin authentication, database, content publishing and a working solver require a backend in a later stage.
The chapter content is sample/template content and needs to be filled with accurate board-wise lessons and questions.
